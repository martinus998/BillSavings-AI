How matching and privacy work

Labels match after trimming spaces and ignoring letter case. There is no fuzzy matching: rename corresponding labels yourself when necessary. Duplicate labels within one bill are rejected to avoid silently combining separate lines. Totals, subtotals and balances must be entered in the optional total boxes, not as item rows. Blank amounts, ambiguous number formats and malformed lines block the comparison.

Calculation uses integer cents. The selected-item difference is not a guaranteed saving. Inputs stay in memory until you clear the tool, reload or leave; this tool does not intentionally save documents to browser storage. Browser history or form-restoration features are outside this tool's control. The existing site counter can record a page visit, but receives no entered bill text or amounts.

For a file containing a PDF, copy the relevant text into these fields first. Image-only scans need separate transcription; this page does not perform OCR. Keep exported summaries private.
