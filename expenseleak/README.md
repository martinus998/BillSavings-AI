# ExpenseLeak AI prototype

Standalone next-project prototype for U.S. small businesses.

## Working now
- Responsive landing page
- Browser-local CSV parsing
- Recurring vendor detection
- Possible same-vendor/same-amount duplicate flags
- Vendor price increase flags
- Estimated recurring monthly spend

## Intentionally not enabled yet
- Paid checkout
- Server-side AI
- PDF/image uploads
- Account system
- Recurring monitoring

## Launch plan
1. Move this prototype into its own GitHub repository.
2. Deploy a preview URL.
3. Add secure account auth and private storage.
4. Add protected server-side AI analysis for invoices/statements.
5. Add Stripe Full Audit payment and entitlement flow.
6. Add self-service cancellation only when subscription monitoring exists.
7. Test payment, webhook, refund, access removal and mobile UX.
8. Add legal/support pages, analytics, sitemap and Search Console.
9. Enable public paid checkout only after all tests pass.

Positioning must remain informational expense review, not accounting, tax, legal or financial advice. Never guarantee savings.
